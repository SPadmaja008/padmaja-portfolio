# Padmaja S. — Personal Portfolio

A modern, responsive personal portfolio website showcasing my skills, projects, experience, certifications, and achievements as an Information Technology student.

## 🌐 Live Website

**[Visit My Portfolio](padmaja-dev.vercel.app)**

## ✨ Features

- **Home & About:** Introduction and professional profile.
- **Skills:** Technical skills and technologies.
- **Projects:** Project descriptions, GitHub repositories, live demos, and video demonstrations.
- **Experience:** Internship and professional experience.
- **Certifications:** Certificates and achievements.
- **Documents:** Resume and certificate viewing and downloading.
- **Coding Profiles:** Links to coding platforms.
- **Contact:** Contact information and communication options.
- **Admin Dashboard:** Secure login to manage portfolio content, documents, and project links.

## 🛠️ Technologies Used

- React
- TypeScript
- Vite
- Supabase
- HTML
- CSS
- JavaScript
- Vercel

📂 Project Highlights

The portfolio includes an admin dashboard that allows me to update my information, add new projects, upload certificates, replace my resume, and manage project resources without rebuilding the website for every content update.

🚀 Deployment

The website is deployed using Vercel and connected to GitHub for automatic deployments.
